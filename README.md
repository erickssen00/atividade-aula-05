👾 GameShow 🎮

Site simples de uma loja fictícia de jogos retrô, desenvolvido em HTML como atividade da aula 5.

Sobre o projeto

A página apresenta a loja GameShow, destacando:

Nome e descrição da loja
Imagem de divulgação
Características da loja
Link para o Instagram
Área de ofertas
Tabela com preços de jogos
Navegação entre as partes da página
Tecnologias utilizadas
HTML5
CSS inline

Como executar
Baixe ou clone o projeto.
Abra a pasta no VS Code.
Abra o arquivo index.html.
Execute o arquivo no navegador.
Objetivo

O objetivo do projeto é praticar conceitos básicos de HTML, como títulos, parágrafos, listas, imagens, links, tabelas e navegação dentro da própria página.
